Brainserver Backup

Privacy policy

Drive access

Brainserver Backup is operated for private backup use. The operator authorizes the Google Drive API so the tool can find the designated backup folder, upload compressed backups, verify their integrity and remove expired backup files. The OAuth scope permits Drive-wide access. The scheduled job uses the designated backup folder for these operations.

Storage and retention

Backup files are stored in the operator’s Google Drive. The job keeps backups for the most recent seven calendar dates. OAuth credentials are stored in the backup server’s restricted configuration. The public information pages do not contain backup data or credentials.

Use and sharing

Google Drive data is used solely to operate the backup and retention job. The tool does not sell Drive data, use it for advertising or share it with unrelated parties. Its use of Google API data follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The operator can revoke the tool’s access in Google Account connections and manage stored files directly in Google Drive. For questions, use the support contact shown on the Google consent screen.
